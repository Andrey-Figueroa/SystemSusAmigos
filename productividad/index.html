¿Cómo se calcula el puntaje?

Cada indicador se compara contra la mejor persona del período (la mejor = 100) y se suman con estos pesos:

    Eficiencia: cada trabajo se compara contra el tiempo promedio del equipo para el mismo servicio en el mismo tipo de vehículo. Más de 1,00 = más rápido que el promedio.

    Tiempo: es aproximado, desde que entró la orden hasta que se pasó a Terminado. Si una persona hizo detallado y mecánica en la misma orden, ese tiempo se cuenta una sola vez.

    Ingreso: el monto del área (detallado o mecánica) tal como se cobró. Si varias personas hicieron la misma área, cada una queda con el monto completo.
